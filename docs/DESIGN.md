# Happy PDF design

**Feel:** sunny, friendly and calm. Material 3 colour roles with Samsung One UI proportions:
a soft grey-beige canvas, white grouped cards, large titles, pill buttons, generous corners.

## Colour
- **Honey** (`--hp-primary`) is the one action colour: filled buttons, links, focus, progress.
- **Sunny** (`--hp-primary-container`) marks what is selected: chips, the current tab, icon tiles.
- **Sun** (`--hp-sun`) is decoration only (logo, illustrations), never text.
- Status colours (success, warn, danger) only describe outcomes, never actions.
- Every text colour clears WCAG AA 4.5:1 on every surface it can sit on, in both themes.

## Type
Figtree, bundled with the app. Sizes: 12, 14, 16, 18, 22, 28, 36 px. Titles 700–800 weight, body 400, labels 600.

## Shape and space
4 px grid. Corners: 12 / 16 / 24 / 28 px, pills for buttons and chips. Touch targets are at least 48 px.

## Rules
- One filled button per screen: the main action.
- Ads never appear while a document is open or being processed.
- Every screen works at 320 px wide and at 200% text without sideways scrolling.
- Respect reduced motion; animation is never needed to understand state.

The live reference is the `/design` page of the app.
