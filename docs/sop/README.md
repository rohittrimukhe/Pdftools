# Standard operating procedures

Public, step-by-step instructions for every task a person does by hand. Each SOP uses
the template below and is written or updated in the same pull request as the work it
describes.

| SOP | Status |
|---|---|
| [Run the app locally](run-locally.md) | Ready |
| [Make a pull request and pass the quality gate](pull-request.md) | Ready |
| [Deploy the website to GitHub Pages](deploy-github-pages.md) | Ready |
| [Turn ads on or off](ads.md) | Ready |
| [Build the desktop and phone apps](native-apps.md) | Ready (store publishing once accounts exist) |
| Connect a custom domain through Cloudflare | Planned (step 14) |

## Template

```
# <Task name>

**Who:** <role>  **When:** <trigger>  **Time:** <minutes>

## Before you start
- <access, tools, accounts>

## Steps
1. <action> — expected result: <what you should see>

## Check it worked
- <how to verify>

## If something goes wrong
- <symptom> → <fix>
```
